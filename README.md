# Super Sales Dashboard - Power BI

## Overview
This project is an interactive Power BI dashboard developed using the Superstore Sales dataset. The dashboard provides business insights by analyzing sales performance, profit, quantity, orders, customer segments, regions, and states through interactive visualizations.

## Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity Sold
- Total Orders
- Sales by Category
- Sales by Region
- Sales by State (Map)
- Sales by Segment
- Sales Trend Over Time

## Tools Used
- Microsoft Power BI Desktop
- Superstore Sales Dataset

## Key Insights
- Analyzed sales performance across different product categories.
- Compared sales distribution by region and customer segment.
- Identified sales trends over time.
- Visualized state-wise sales using an interactive map.
